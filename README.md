# Alexus University (versión de prueba · modo invitado)

Plataforma educativa gratuita sobre finanzas personales e inversión: campus 3D, lecciones, calculadoras y práctica con dinero ficticio.

- **No es asesoramiento financiero.** Contenido educativo; invertir conlleva riesgo; solo para mayores de 18.
- Esta edición no tiene cuentas ni servidor: el progreso se guarda solo en el navegador de cada persona.
- Contacto: ver `legal/aviso-legal.html`.
- Licencias de terceros: carpeta `licenses/` y `people/LICENSE-Rocketbox.txt`.

Versión de prueba para una comunidad de aprendizaje.
